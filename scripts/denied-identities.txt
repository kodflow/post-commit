# Identities that must never appear in a commit of a foreign-history
# repository (foreign-history.txt), wherever they sit: author, committer,
# trailer or anywhere in the message. Read only in that mode; everywhere else
# the `authors` allow-list already refuses them, and more.
#
# One lowercase hex SHA-256 per line, of either
#   · a whole address, lowercased:   printf '%s' 'name@example.com' | sha256sum
#   · a whole domain, `@` included:  printf '%s' '@example.com'     | sha256sum
# A domain entry refuses every address at that domain. Blank lines and
# #-comments are ignored.
#
# Digests, not addresses: this repository is public, and a list of the
# addresses it exists to keep out of histories would publish them itself.
# A digest only confirms an address to someone who already has it.
