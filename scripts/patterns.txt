# Forbidden patterns — one ERE per line, matched case-insensitively against
# each commit's full message AND its author/committer identity. Blank lines
# and #-comments are ignored.
#
# Single source of truth for the fleet: a rule added here is live in every
# repo pinned to kodflow/post-commit@main on its next run.
#
# DESIGN — attribution-SHAPED, not keyword matches. Measured on the real
# history of devcontainer-template: a bare `.claude/` rule matches 25 of the
# last 60 commits and `claude[- ]code` matches 2 — on the template's own
# legitimate commits. Every default pattern therefore matches the shape of an
# attribution (a trailer, a "generated by" banner, a bot identity), not the
# mention of a vendor. Keyword rules live in patterns-strict.txt, opt-in.
#
# --- attribution trailers ------------------------------------------------
# git's own default capitalisation is "Co-authored-by:" (lowercase second
# word). The pre-#447 hook patterns were case-SENSITIVE and only ever matched
# "Co-Authored-By:", missing the single most common real-world shape.
^[[:space:]]*(co-authored-by|assisted-by|generated-by|authored-by|committed-by|reviewed-by|signed-off-by)[[:space:]]*:.*(claude|anthropic|openai|chatgpt|gpt-[0-9]|copilot|gemini|codeium|cursor|devin|aider|llm|[^a-z]ai[^a-z])
noreply@anthropic\.com
copilot@users\.noreply\.github\.com
# --- "generated by" banners ----------------------------------------------
# \[? tolerates the markdown link form "Generated with [Claude Code](…)".
generated[[:space:]]+(by|with|using)[[:space:]]+\[?(claude|ai|gpt|chatgpt|anthropic|copilot|gemini|cursor|devin|aider|an?[[:space:]]+llm)
🤖
# --- self-declared assistance --------------------------------------------
\bai[-[:space:]]?(assisted|generated|authored|written)\b
\b(written|authored|generated)[[:space:]]+by[[:space:]]+an?[[:space:]]+(ai|llm|language[[:space:]]model)\b
