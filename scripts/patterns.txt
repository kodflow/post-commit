# Forbidden patterns for commit messages — one ERE per line, matched
# case-insensitively (grep -iE). Blank lines and #-comments are ignored.
#
# This file is the single source of truth for the fleet. Adding a rule here
# propagates to every repo whose post-commit.yml points at @main, with no
# per-repo change.
#
# DESIGN NOTE — why these are attribution-SHAPED, not keyword matches.
# ktn-linter's local hook can afford a blunt `claude[- ]code` keyword: the
# failure mode there is "re-word your message and commit again", one
# developer, one second. Fleet-wide in CI the same pattern would fail every
# PR on devcontainer-template, ktn-linter and marketplace — repos whose
# subject matter IS Claude Code, where "docs: update claude code settings"
# is a legitimate commit. Every default pattern below therefore matches the
# *shape of an attribution* (a trailer, a "generated by" banner, a bot
# identity), not the mere mention of a vendor. Keyword matches live in
# patterns-strict.txt, opt-in per repo.
#
# --- AI attribution trailers -------------------------------------------
# git's own default trailer capitalisation is "Co-authored-by:" (lowercase
# second word). The pre-#447 patterns were case-SENSITIVE and matched only
# "Co-Authored-By:", so the single most common real-world shape was never
# caught. Everything here relies on the -i applied by the runner.
^[[:space:]]*(co-authored-by|assisted-by|generated-by|authored-by|committed-by)[[:space:]]*:.*(claude|anthropic|openai|chatgpt|gpt-[0-9]|copilot|gemini|codeium|cursor|devin|llm|[^a-z]ai[^a-z])
noreply@anthropic\.com
copilot@users\.noreply\.github\.com
# --- "generated by" banners --------------------------------------------
# Catches "🤖 Generated with [Claude Code](…)" via the bracket-tolerant \[?
generated[[:space:]]+(by|with|using)[[:space:]]+\[?(claude|ai|gpt|chatgpt|anthropic|copilot|gemini|cursor|devin|an? llm)
🤖
# --- self-declared assistance ------------------------------------------
\bai[-[:space:]]?(assisted|generated|authored|written)\b
\b(written|authored|generated)[[:space:]]+by[[:space:]]+an?[[:space:]]+(ai|llm|language[[:space:]]model)\b
